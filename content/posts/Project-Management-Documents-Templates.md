As a project manager, you will create a lot of documents to document each phase of your project.  Sometimes there are multiple type of documents needed in a phase.  Documenting is a tedious task to do, nevertheless it is necessary to write it, so you can track it, submit it to the relevant party and retrospect to it sometime later after the project completed.

This is an article series, I will write down every template document needed in each phase so you will only download the template, write down the content and adjusted it accordingly, when needed.

Project phases and document needed:

1. **Initiation Phase**
   1. Project Charter
   2. Scope of Work
   3. Stakeholder Register/Analysis
2. **Planning Phase**
   1. Project Management Plan
   2. Project Budget
   3. Risk Management Plan
   4. Communication Plan
   5. Resource Management Plan
3. **Development Phase**
   1. Status Report
   2. ROAM Analysis
   3. Budget Burndown/Tracking Chart
   4. Gantt Chart
   5. Retrospective Note/Templates
4. **Closing Phase**
   1. Project Closeout report
   2. Final Project Deliverables & Handover Document
